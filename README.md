# SA CheatBoard

Personal-use cheat reference for GTA San Andreas on Android (classic mobile edition).
Searchable cheat list (87 mobile cheats), favorites, and a small floating icon over the game that opens the list and copies a code when tapped.
No internet permission, no ads, no libraries.

## Install (no PC needed)
Open the **Releases** page of this repo on your phone, download `SA-CheatBoard.apk`, and install it
(allow "install unknown apps" for your browser when asked). It is a debug-signed build of the source in this repo.

## Setup
1. Open the app > **1 Overlay permission** > allow.
2. **2 Start overlay** > the small "SA" icon appears over the game. Drag it, tap it to open the list, tap a cheat to copy it.

## Entering cheats
The classic mobile version only accepts cheats from a hardware keyboard (USB with an OTG cable, or Bluetooth).
Type the full phrase during gameplay, e.g. `INEEDSOMEHELP`. "Cheat Activated" confirms it.
On-screen keyboard apps (including this project's earlier keyboard and Hacker's Keyboard) never reach the game, because it never opens a text input.
If your game has Options > Accessibility > Enter cheat code, use that instead.

## Notes
- Mobile uses full phrases, not the short PC codes (HESOYAM etc.).
- Cheats can fail some missions and disable achievements.
